Do not invoke unrelated stacks, AI features, branding or deployment capabilities.

No new application dependency or framework is needed. Compare production assets before/after and exercise all operational routes.
4. Audit package locks with npm advisory data. Apply compatible fixes without force, then report any unresolved advisories with actual exposure and compatibility limits. Preserve package major versions and existing overrides.
5. Verify regression tests for security behavior, real browser keyboard/tab/form contracts, all route loads, both themes, 320px/mobile/desktop overflow and reduced motion. Run typecheck, unit and isolated PostgreSQL integration/concurrency suites plus builds. Record real output and local evidence locations; do not count recommendations or static scans as execution.
